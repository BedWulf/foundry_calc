# Аудит номенклатуры: отливки, формы и годовой металл

30 октября 2026. Проверки **физических связей** исходных данных,
а не соответствия числам учебных дипломов.

## Размерности и независимые расчётные равенства

Для **одной позиции** номенклатуры:

- `Q` — количество отливок *с учётом брака*, шт/год.
- `G` — количество отливок в одной форме, шт/форму.
- `N` — количество форм за год, форм/год.
- `L` — общая масса металла, заливаемого **в форму**, кг/форму.
- `M` — годовой расход заливаемого металла для позиции, т/год.
- `C` — указанная масса одной отливки *с ЛПС*, кг/отливку.

При независимом изготовлении форм для каждой позиции должны
выполняться следующие связи:

```text
N = ceil(Q / G)                           [форм/год]
M = N × L / 1000                         [т/год]
```

Единицы количества отливок в форме теперь сохраняются в
`CastingItem.castings_per_mold`, а не теряются после импорта Excel.
В старых файлах это поле может отсутствовать: в таком случае
`0` означает **неизвестно**, не «одна отливка в форме».

Если `L` не было в Excel, предыдущий импорт оценивал его как
`C × G`. Такой результат остаётся оценкой и теперь явно имеет
`pouring_mass_estimated=True`; подтверждённым паспортным значением
технологической карты он не является.

## Проверка совместимости C и L

Для отдельной формы сумма массы отливок и распределённой литниковой
системы не может быть больше полной заливки. Но если `C` уже включает
часть ОБЩЕЙ для нескольких отливок ЛПС, произведение `C × G`
может повторно учитывать общий металл. Поэтому `L < C × G` — это
**несогласованность определений исходных данных**, требующая проверки,
а не автоматическое доказательство ошибочной геометрии и не основание
тихо увеличить массу заливки.

Во всех трёх проверках система показывает проблему, но **не переписывает
цифры Excel или пользовательского проекта** для совпадения с формулой.
Для проверки количества отливок без брака потребуется отдельно
уточнить технологию расчёта брака: нельзя отождествлять `Q` с
годным выпуском.

## Достоверность и интерфейс

- В таблице номенклатуры добавлена колонка «Отливок/форму».
- Для строк с неполными данными, несогласованным количеством форм,
  объёмом заливки или годовой массой выдаётся предупреждение.
- Краткий счётчик замечаний и подробные сведения доступны через
  подсказку рядом с итогом номенклатуры.
- В сводке проект **не считается полностью проверенным**, если
  существуют такие замечания. Первые 16 включены в перечень
  предупреждений, остальные остаются доступными на вкладке исходных
  данных.
- Сохранение проекта с отрицательными количеством форм, кратностью,
  числом отливок или массой отклоняется до замены прежнего файла.
- Старые `.fpro.json` открываются без нового поля, но не получают
  ложное подтверждение кратности.

## Ограничения и следующий этап

- Расчёт предполагает, что позиции имеют **свои отдельные формы**.
  Если в одной форме размещены разные номенклатурные позиции,
  нужно проектировать явную спецификацию совместной формовки,
  а не суммировать формы независимо.
- Нет подтверждения распределения общей ЛПС между отливками.
- Источник `C`, `L` и данных о браке может требовать проверки по
  чертежам и технологической карте — диплом не является доказательством.
- Следующий этап должен добавить индивидуальную проверку исходных
  полей по каждой позиции (в том числе количества стержней), а не
  единый признак подтверждения для всей номенклатуры.
