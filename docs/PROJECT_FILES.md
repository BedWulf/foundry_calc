# Сохранение и открытие проекта (формат .fpro.json)

Начиная с рабочего этапа сохранения проектов, можно сохранить расчёт **целиком** в отдельный файл `*.fpro.json`, продолжить работу после перезапуска приложения и перенести проект на другой ПК.

## Команды программы

На верхней панели и в меню **«Файл»** есть:

| Действие | Горячая клавиша | Результат |
|---|---|---|
| Новый проект | Ctrl+N | Создать независимую программу |
| Открыть проект | Ctrl+O | Выбрать сохранённый `*.fpro.json` |
| Сохранить | Ctrl+S | Записать изменения в прежний файл |
| Сохранить как | Ctrl+Shift+S | Указать другой файл/папку |

При первом сохранении выбирается путь. Звёздочка `*` в заголовке означает, что есть несохранённые изменения. При закрытии, создании другого проекта или открытии файла программа спрашивает: **Сохранить / Не сохранять / Отмена**. Отмена не удаляет данные.

## Что сохраняется

- Название, дата, заказчик, годная программа в тоннах, материал, плотность, сменность, брак, потери.
- **Все поля каждой отливки**: программа с браком, число форм, масса заливки, размеры, опоки, стержни, машина, обозначение чертежа и другие параметры.
- Настройки формовочных партий, переналадки, максимальная загрузка, автоматический/ручной режим, **количество линий каждой модели**, одновременно работающие линии.
- Выборы оборудования из отделений, которые приложение хранит через `UserChoices`: печи, формовочные, стержневые, смесеприготовление, очистка, склад, транспорт.
- Пользовательские справочники оборудования из разрешённых `custom_*.json` для переноса на другую машину; при открытии они **добавляются** к локальным, но не стирают чужие записи.

**Расчётные результаты (потребность, фонд, загрузка и т. п.) пересчитываются при открытии**, а не принимаются на веру из старого файла. Так безопаснее после исправлений инженерных формул.

## Как проверить на двух дипломах

1. Импортируйте «Диплом 1» из `examples/` или из раздела «❓ Руководство»; убедитесь, что указаны 20 отливок.
2. В формовке выберите ручной парк и настройте число линий, количество партий, переналадки.
3. Нажмите **«Сохранить как»**, например `Diplom_1.fpro.json`.
4. Создайте новый проект, импортируйте «Диплом 2», сохраните под другим именем.
5. Снова откройте `Diplom_1.fpro.json`: должны вернуться **именно его** отливки, опоки, количества линий и исходные цифры.
6. Измените значение в исходных данных — появится `*`. Нажмите Ctrl+S; звёздочка исчезнет.
7. Повторите проверку сохранения, закрытия EXE и открытия проекта после перезапуска.

Важно: экспорт «Сводки» в Excel — это **отчёт**, а файл `*.fpro.json` — **полная рабочая модель**. Их нельзя подменять друг другом.

## Защита и совместимость

Файл проекта является читаемым UTF-8 JSON, но не требует ручного редактирования. Формат содержит маркер `liteynyi-tseh-project` и версию `1`. Повреждённые файлы или неизвестная версия отклоняются **до замены открытого проекта**. Запись ведётся через временный файл с атомарной заменой, чтобы ошибка записи не оставила половину проекта.

Выборы оборудования глобально также хранятся в профиле Windows. При повторном открытии проекта архивные выборы восстанавливаются именно для него; чужие сохранённые проекты не удаляются. Конфликтующие пользовательские модели с одинаковым `id` не заменяются молча: программа попросит разобрать конфликт.

Сохраняйте резервную копию `*.fpro.json`, особенно перед переходом между версиями. **Программа создаёт отдельные аварийные снимки несохранённой работы**, но не ведёт версионные копии основного файла и не выполняет облачной синхронизации. [Как работает автовосстановление](RECOVERY_AUTOSAVE.md). Поддерживается только формат версии 1, а устаревший несохранённый проект из предыдущей версии автоматически не восстанавливается: сначала потребуется исходная дипломная таблица.
