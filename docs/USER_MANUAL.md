# Руководство пользователя — ЛитейныйЦех PRO

*Версия руководства: 2026-10-29. Для первых расчётов, без знаний Python.*

> **Важно.** Программа помогает подготовить **предварительную инженерную модель** литейного цеха. Результат не заменяет проект технолога, нормативные расчёты, паспортную проверку оборудования и испытания производственного графика. «Достаточно за год» не означает «успеваем каждый час».

## Обучение внутри программы — только по вашему желанию

**При первом запуске** приложение один раз предложит пройти интерактивную экскурсию. Нажмите **«Начать обучение»** или **«Не сейчас»**. В обоих случаях окно с предложением больше **не появляется при последующих запусках** в этом профиле Windows. Режим можно запустить когда угодно самостоятельно: **«❓ Руководство» → «▶ Начать обучение по программе»**. Даже если закрыли экскурсию посередине, повтор автоматически не запускается.

Экскурсия показывает **реальные разделы** и подсказку сверху; переходы **«Назад»**, **«Далее»** и **«Прервать обучение»** работают без сохранения или изменения вашего проекта. На последнем шаге нажмите «Завершить». Можно продолжить работу с той вкладки, на которой были до экскурсии.

Для практики в «❓ Руководство» есть кнопка **«Сохранить учебный Excel»**. Она создаёт файл с двумя **условными учебными отливками** и не импортирует его автоматически. Чтобы потренироваться с импортом, откройте **«Исходные данные» → «Импорт из Excel»** и выберите файл. Если в текущем проекте уже есть номенклатура, программа спросит подтверждение замены — на рабочих данных нажмите **«Нет»**. Текущая версия не умеет полноценно сохранять весь проект, поэтому перед заменой держите исходный Excel отдельно.

Первичное предложение хранится в пользовательском профиле: `%APPDATA%\\LiteynyiTsehPRO\\onboarding.json` (в готовой Windows-сборке). Оно не зависит от имени проекта, года и количества запусков программы. На другом профиле Windows это будет отдельный первый запуск.

## 1. С чего начать

1. Откройте приложение `LiteynyiTsehPRO.exe` из **распакованной папки целиком**. Python для запуска готовой Windows-сборки не нужен. Если программы пока нет, см. `WINDOWS_BUILD.md`.
2. В левом меню выберите **«Исходные данные»**.
3. Выберите категорию металла и марку сплава. Проверьте годовую программу и единицы измерения.
4. Загрузите **номенклатуру из Excel** кнопкой **«Импорт из Excel»**. После импорта проверьте таблицу: **форм/год, опока, заливочная масса, металл/год**.
5. Просмотрите **«Фонды времени»**. Сравните фонд оборудования с выбранным режимом цеха.
6. Откройте отделения в порядке слева направо: **Плавильное → Формовочное → Стержневое → Смесеприготовление → Обрубка/Очистка → Склады → Рабочая сила → Площади → Транспорт → Сводка**.
7. В разделе **«Сводка»** проверьте **«Баланс мощностей и узкие места»** и предупреждения. Экспортируйте Excel только после проверки значений.

## 2. «Исходные данные» — что вводить

| Поле в программе | Что писать | Единицы |
|---|---|---|
| Название проекта | Уникальное имя расчёта | текст |
| Заказчик | Необязательно | текст |
| Категория / Сплав | Сначала материал, затем марка из справочника | список |
| Годовой выпуск | Планируемый **годный** выпуск цеха | **т/год** |
| Марка сплава | Текстовое обозначение (проверьте, что категория соответствует справочнику) | текст |
| Плотность сплава | Фактическая плотность принятого сплава | кг/м³ |
| Смен в сутки | 1, 2 или 3 в типовом режиме | смен/сутки |
| Часов в смене | Продолжительность смены, например 8 | ч/смену |
| Рабочих дней в году | Принятый производственный календарь | дней/год |
| Брак | Доля брака, принятая в общей программе | % |
| Литники и прибыли | Добавочная масса литниковой системы и прибылей в общем балансе | % |
| Угар | Потеря металла при плавке | % |

**Проверьте согласованность:** ввод `37 000` в «Годовой выпуск» означает **37 000 тонн в год**, а не 37 000 штук отливок. В Excel ниже количество задаётся в штуках — это разные показатели. Не используйте одновременно два различных годовых плана без проверки баланса.

Поля с процентами нельзя заполнять десятичной долей: **5 означает 5%, а не 0,05%**.

## Проверочные Excel из двух дипломов

В **«❓ Руководство»** есть кнопки **«Сохранить Excel диплома 1»** и **«Сохранить Excel диплома 2»**. Нажмите нужную, выберите папку и сохраните файл. В каждом файле три листа: **«Ведомость формовки»** (данные диплома без исправлений), **«Импорт A-P»** (контрольный шаблон) и **«Сверка»** (отличия исходных значений и вычислений).

Для ручного теста откройте **«Исходные данные» → «Импорт из Excel»**, выберите сохранённую книгу и проверьте, что загрузилось **20 отливок**. Файл из диплома №1 содержит 5 271 000 отливок в год и **1 368 325** физических форм при округлении. Диплом №2 — 9 001 281 отливку в год и **768 159** физических форм. Эталонная сверка с цифрами оригинала остаётся на отдельном листе.

Импорт **не** является обратным экспортом: экспорт «Сводки» создаёт расчётный отчёт с другим форматом, а не таблицу новых входных данных. Для повторного ввода используйте именно исходную ведомость или A–P; экспортированная сводка не является шаблоном импорта.

## 3. Два варианта Excel для импорта

**Вариант А — оригинальный Excel от преподавателя.** Можно загрузить книгу целиком, например `tablitsy_kursach.xlsx`: программа найдёт вкладку **«Таблица 8»** по содержимому заголовков и возьмёт из неё номенклатуру. От пользователя не требуется переставлять колонки или удалять «Таблицу 1» и «Таблицу 2». Эти два листа содержат расчёт производственной программы и брака, а не ведомость формовки.

В преподавательской «Таблице 8» позиции начинаются **с 7-й строки**, а значения находятся в следующих ячейках:

| Колонка преподавателя | Значение |
|---|---|
| A–C | Номер, наименование, масса отливки (кг) |
| D–F | Длина, ширина и высота отливки (мм) |
| G–H | Отливок в год с учётом брака; отливок в одной форме |
| I | Форм/год в исходной таблице (**может быть дробным**) |
| J–K | Габарит опоки, две высоты полуформ (мм) |
| L–M | Заливочная масса (кг на форму); металл в год (кг) |
| N–O | Смесь на форму, смесь в год (м³) |
| P | Формовочная машина, иногда одна объединённая ячейка |

Пример из преподавательского файла: **9 001 281 отливка в год**, сумма исходных форм **768 151,12**, округление требуемых физических форм по каждой позиции вверх даёт **768 159 форм/год**. Исходная масса заливаемого металла **79 814 786,09 кг**, а после индивидуального округления форм она станет несколько выше. В книге у этих величин **разные основания расчёта**. Импортёр сохраняет исходные данные в файле и показывает предупреждения о расхождениях; не приравнивайте их автоматически к ошибкам студента.

**Вариант Б — простой шаблон A–P.** Его формат описан ниже. В нём данные начинаются с четвёртой строки первого листа. Оба формата поддерживаются, но значения и единицы двух источников нельзя смешивать.

### Простой шаблон A–P

Поддерживается файл **.xlsx / .xlsm**. Данные начинаются с **4-й строки**; первые 3 строки оставьте под заголовки. Используйте первый лист книги.

| Колонка | Смысл | Пример |
|---|---|---|
| **A** | Номер позиции | 1 |
| **B** | Наименование отливки | Корпус |
| **C** | Масса **одной отливки с ЛПС** | 10 кг |
| **D** | Габариты отливки | `130x150` мм |
| **E** | Высота отливки | 60 мм |
| **F** | **Отливок в год, с учётом брака** | 1001 шт |
| **G** | Сколько отливок размещено **в одной форме** | 2 шт/форму |
| H | Расчётная колонка — можно оставить пустой | — |
| **I** | Длина опоки | 900 мм |
| **J** | Ширина опоки | 600 мм |
| **K** | Высота верхней/нижней полуформы | `200/250` мм |
| **L** | **Масса заливаемого металла на ОДНУ форму** | 23 кг/форму |
| M | Расчётная колонка — можно оставить пустой | — |
| **N** | Объём формовочной и стержневой смеси (проверьте исходную методику) | м³ |
| O | Расчётная колонка — можно оставить пустой | — |
| **P** | Наименование формовочной машины, справочное | ИЛ-225 |

**Пример:** если F = 1001 отливка, G = 2 отливки/форму, нужно **501 форму в год** (округление вверх). Если L = 23 кг металла на форму, заливка равна **501 × 23 / 1000 = 11,523 т/год**.

**Не путайте:** C — масса отливки с литниковой системой, **L — весь металл, заливаемый в форму**. Если L оставить пустой, импортёр показывает предупреждение и оценивает L = C × G; это только предварительная оценка, её необходимо проверить. Если K заполнена одной высотой, программа предполагает одинаковую высоту двух полуформ — проверьте её.

В этой форме Excel **F уже включает брак**. Программа не должна начислять брак второй раз при преобразовании F в количество форм. Точная годная масса и индивидуальный процент брака позиции из текущего формата Excel **не восстанавливаются автоматически**.

Перед расчётом проверьте, что все позиции появились в таблице после импорта. Кнопка **«Очистить»** удаляет номенклатуру из текущего расчёта.

## 4. «Фонды времени»

Это результат, а не место для повторного ввода программы. Смотрите **действительный фонд оборудования, Фд.об (ч/год)** и **действительный фонд рабочих, Фд.р (ч/год)**. Эти два фонда различаются. Если изменили режим работы на предыдущем экране, обновите расчёт и убедитесь, что значения соответствуют принятому календарю.

## Удобный просмотр таблиц и подбор оборудования

Главное окно открывается **развёрнутым** и адаптируется к размеру экрана. В разделе **«Исходные данные» → «Номенклатура отливок»** доступна кнопка **«↗ Развернуть таблицу»**. Она открывает отдельное увеличиваемое окно с полной ведомостью, поиском по любому столбцу (название отливки, опока, количество форм) и сортировкой по заголовкам. Исходные данные при просмотре не изменяются.

В отделениях с подбором оборудования нажмите **«↗ Развернуть выбор»**, чтобы увидеть карточки в большом окне с прокруткой. Выберите оборудование, затем **«Применить»**; кнопка «Отмена» оставит прежний выбор. В отчёте под кнопкой **«Заполнить ручной парк по автоподбору»** тёмный фон и светлый текст; все редакторы и диалоги используют общую нейтральную тёмную тему.

Окна импорта, добавления оборудования и добавления сплава можно увеличивать. Выбор файлов открывается в тёмном диалоге Qt, а не в зависящем от темы Windows системном окне.

## 5. «Формовочное» — выбор линий

В блоке **«Общий парк — последовательный выпуск партиями»** выберите:

- **«Автоматический подбор»** — программа предварительно определяет парк по программе и совместимости.
- **«Вручную: указать количество каждой модели»** — самостоятельно задайте количество установленных линий: **0** означает, что эта модель **не используется**. Варианты можно взять кнопкой **«Заполнить ручной парк по автоподбору»**, а затем исправить.

Другие поля этого блока:

| Поле | Пример | Пояснение |
|---|---|---|
| Партий в год на позицию | 4 | Сколько раз за год запускается данная позиция |
| Переналадка каждой партии | 2 ч | Время подготовки оборудования перед партией; **0 ч — оптимистичное допущение** |
| Максимальная годовая загрузка | 0,85 | Линия может занимать до 85% заданного годового фонда |

**Одна линия может поочерёдно выпускать разные позиции**, если подходят опоки, технология и массы. Увеличив число линий, вы не увеличите автоматически заданную годовую программу; снизится загрузка и увеличится требуемая площадь и персонал. Если линий недостаточно, вы увидите **дефицит форм/год**, а не скрытое добавление оборудования.

## 6. Остальные отделения

- **Плавильное**: выберите печь, проверьте количество печей, требуемую металлозавалку в **т/год** и загрузку.
- **Стержневое**: проверьте число стержней на форму (из номенклатуры или ручного ввода), стержней в год и выбранную машину.
- **Смесеприготовление**: отдельно смотрите каждую операцию; часть потоков считается в **м³**, другая — в **тоннах**. Без плотности нельзя подменять эти единицы друг другом.
- **Обрубка/Очистка**: просмотрите операционный парк оборудования и необходимые годовые объёмы.
- **Склады**: проверьте исходные нормы запасов и площади. Не считайте склад полностью спроектированным без логистики.
- **Рабочая сила**: это предварительная численность по укрупнённым коэффициентам, а не утверждённое штатное расписание.
- **Площади**: число линий влияет на площадь размещения. Если производственный план не выполняется, итог здания помечается как **неполная оценка**.
- **Транспорт**: проверьте ковши и краны. Годовая ёмкость не равна подтверждённой посменной пропускной способности.

## 7. Как читать «Сводку»

Вкладка **«Сводка»** показывает оборудование, годовой **«Баланс мощностей и узкие места»**, предупреждения и кнопку **«Экспорт в Excel»**.

Статусы:
- **По году достаточно**: годовая потребность укладывается в рассчитанную мощность; расписание смен **ещё не подтверждено**.
- **ДЕФИЦИТ**: нет нужной годовой мощности; меняйте количество оборудования, фонд времени или модель.
- **Не проверено**: отсутствуют данные или требуются посменные/транспортные сведения. **Это не означает, что всё хорошо.**

## 8. Проверка работы в течение смены

На вкладке **«Формовочное»**, в блоке **«Общий парк — последовательный выпуск партиями»**, есть поле **«Линий одновременно в смену»**:

- **«Все производящие линии» (0)** — максимальный стресс-сценарий: все линии, где запланированы отливки, работают одновременно.
- **1, 2, 3…** — ограничить число одновременно работающих линий. Программа выбирает наибольшие расходы на линиях для каждого ресурса **независимо**. Это верхняя оценка, не попытка построить расписание.
- Время смены берётся из **«Исходные данные» → «Часов в смене»**.

Вкладка **«Сводка» → «Сменный сценарий»** показывает потребность металла (**т/смену**), теоретическую подачу жидкого металла печами с поправкой на введённый угар, пропускную способность рабочих ковшей и изготовление стержней (**стержней/смену**). Для корректной проверки в Excel нужна **L — заливочная масса на форму**. Количество стержней на форму не импортируется из текущего Excel-шаблона, поэтому проверка подачи стержней может честно показать **«Не проверено»**. Подача смеси по такту также ещё не рассчитана.

Дополнительная проверка сменной нагрузки — **стресс-сценарий**, а не детальный календарь. При одновременном выпуске на нескольких линиях потребность в жидком металле, стержнях и транспорте может кратковременно превышать подачу, даже когда годовая мощность достаточна. Если такой сценарий показывает дефицит, проверьте возможность разнесения партий, запасы и фактический такт. Если сценарий показывает достаточность, это **ещё не подтверждает** движение всех материалов по минутам и безопасность процесса.

## 9. Что сохраняется

Выбор оборудования и режим формовочных линий записываются в пользовательские настройки (на Windows — `%APPDATA%\\LiteynyiTsehPRO`). **В текущей версии отсутствует отдельное полноценное сохранение и восстановление всей номенклатуры проекта**. Сохраняйте исходный Excel отдельно, чтобы можно было повторно загрузить данные. Не редактируйте встроенные паспортные справочники без подтверждённых источников.

## 10. Перед передачей расчёта технологу

Проверьте исходный Excel, единицы, паспортные данные оборудования, реальные переналадки, состав парка, отсутствие критических дефицитов, посменные режимы, смесеприготовление, ковши и логистику. В Excel-экспорте обязательно приложите объяснения всех статусов «Не проверено». Не выдавайте учебные нормативы за рабочий проект без независимой проверки.
