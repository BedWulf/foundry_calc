# Подтверждение технологических данных каждой отливки

Аудит 30.10.2026, развитие политики `ENGINEERING_VERIFICATION_POLICY.md`.

## Цель

Дипломы используются как учебные сценарии, а не как источники
паспортной или технологической истины. Для промышленного расчёта
каждая производимая позиция должна иметь проверенные исходные
технологические данные, без скрытого округления и усреднения.

## Отдельные доказательства по каждой позиции

В `CastingItem` введены:
- `cores_count_verified`, `cores_count_source` — число стержней
  на одну форму проверено по конкретному документу. Ноль означает
  отсутствие стержней **только при подтверждении** либо при старом
  общем подтверждении проекта.
- `mass_casting_verified`, `mass_casting_source` — чистая масса
  одной отливки (кг/отливку) и её документальное основание.
- Незаполненная масса 0 — **неизвестно**, не нулевая физическая масса.

Во вкладке «Исходные данные» выделите позицию и нажмите
**«Проверить позицию»**. Заполните число стержней и чистую массу,
поставьте соответствующие отметки после сверки с чертежом,
техкартой или другим документом. Ссылка/обозначение документа
обязательно для каждой отметки. Данные других позиций не меняются.
При новой импортируемой номенклатуре подтверждения не переносятся.

Для старых файлов без новых полей всё по умолчанию неподтверждено.
Старый общий флаг `cores_zero_confirmed` оставлен ради совместимости,
но он не доказывает происхождение каждого нуля и не заменяет
индивидуального подтверждения, требуемого для общей готовности проекта.

## Две независимые проверки

- **Арифметическая согласованность** (`audit_castings`):
  `N = ceil(Q/G)`, `M = N × L / 1000`, контроль определения
  чистой и заливочной массы и отсутствия противоречивых величин.
- **Достоверность источника** (`audit_casting_technology`):
  указывает для каждой производимой позиции, что ещё не
  подтверждено по документу. Отдельно выявляет физически
  сомнительную чистую массу, превышающую массу с ЛПС.

Успешное прохождение математических тождеств не доказывает
истинность чисел из справочника или исходной ведомости.
В сводке и большом просмотрщике номенклатуры видны обе категории.

## Важное исправление точности стержневого расчёта

Вместо `ceil(ΣNформ × round(k_среднее, 2))` используется
точная целочисленная сумма:

```text
N_стержней_год = Σ (N_форм,i × n_стержней_на_форму,i)
```

Среднее число стержней отображается для удобства, но **не
служит округлённой базой расчёта**. Например 1 форма с одним
стержнем и 100 форм без стержней дают ровно 1 стержень в год,
а не 2 при округлении среднего до 0,01.

Если ручное среднее переопределено или годовое количество форм
в формовочном отделении не совпадает с суммой по позициям,
стержневая мощность считается неподтверждённой. Интерфейс
может показать предварительную оценку, но сводка обязана
показать неизвестную подтверждённую потребность.

## Ограничения

- Число стержней — количество на форму, а масса стержня
  должна подтверждаться отдельно: сохранение двух величин
  в модели не означает точной массы стержневой смеси.
- Отметка пользователя и указанный источник позволяют
  проследить происхождение числа, но программа пока не
  проверяет подлинность чертежа/технологической карты.
- Поля `mass_with_LPS_kg` и `pouring_mass_kg` отдельно
  проверяются на алгебраическую согласованность; детали
  распределения общей литниковой системы требуют отдельной
  технологической модели.
- На следующем этапе можно расширить индивидуальное
  подтверждение на параметры литников, массы и габариты
  отдельных стержней, технологические потери и источники
  производительности оборудования.
