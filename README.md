# ЛитейныйЦех PRO

Рабочая версия инженерного калькулятора литейного цеха: PySide6, автоматический и ручной парк формовочных линий, расчёты отделений и предварительные балансы мощности.

**Первое открытие:** приложение один раз предлагает интерактивную экскурсию. После выбора или закрытия предложение больше не повторяется автоматически. Вручную экскурсию можно заново запускать в «❓ Руководство». Учебный Excel создаётся отдельно и не изменяет текущий проект.

**Два дипломных файла для ручной проверки:** кнопки в разделе «❓ Руководство» сохраняют оригинальные контрольные ведомости локально. Также они лежат в [examples/](examples/), импортируются через «Исходные данные → Импорт из Excel» и не подменяют активный проект автоматически.

**Импорт из преподавательского Excel:** поддерживается книга с тремя листами «Таблица 1», «Таблица 2», «Таблица 8». Импортёр находит «Таблицу 8» и проверяет округление форм/год. Исходный файл менять не требуется. Варианты и единицы описаны в [руководстве](docs/USER_MANUAL.md).

**Новому пользователю:** [пошаговое руководство: что и куда вводить](docs/USER_MANUAL.md). Оно также открывается внутри программы через «❓ Руководство» и кнопку «Что и куда вводить» на вкладке исходных данных.

**Сборка и запуск на чистой Windows:** [WINDOWS_BUILD.md](WINDOWS_BUILD.md).

**Ограничения расчётной модели:** [PLANT_CAPACITY_CHECKS.md](PLANT_CAPACITY_CHECKS.md), [MANUAL_MOLDING_LINES.md](MANUAL_MOLDING_LINES.md).

## Запуск из исходников

```bash
python -m pip install -r requirements.txt
python main.py
```

## Тестирование

```bash
python -m pip install pytest pytest-timeout
python -m pytest -q
```

**Важно:** приложение не строит полноценного технологического календаря, а номинальная мощность оборудования и предварительная оценка площадей не подтверждают нормативную пригодность готового цеха. Проверяйте исходные данные, паспорта машин и предупреждения.

## Структура проекта и исправление запуска EXE

[Текущая организация файлов и правила очистки](docs/DEVELOPER_WORKSPACE.md). Оригинальные дипломные PDF и методичка находятся в [references/](references/); два контрольных Excel остаются в [examples/](examples/).

**Для Windows:** старые архивы со сборками до исправления `core/melting.py` могут падать с `FileNotFoundError: ... _internal\\core\\melting.py`. Перекачайте **полный комплект** из последнего успешного запуска [Build Windows EXE (PySide6)](https://github.com/BedWulf/foundry_calc/actions/workflows/windows-exe.yml) и полностью распакуйте его в **новую пустую папку**. Не подменяйте только один `.exe` в старой сборке. Подробнее — [WINDOWS_BUILD.md](WINDOWS_BUILD.md).
