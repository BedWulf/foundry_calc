# Управление количеством формовочных линий

## Назначение
При постоянной **годовой программе отливок** выбор числа линий меняет их загрузку, состав оборудования, площади и расчёт операционного персонала. Годовую программу, массу металла и массу смеси **нельзя автоматически увеличивать** только потому, что установили больше машин.

## Работа в интерфейсе
1. Вкладка **Формовочное отделение** → блок **Общий парк — последовательный выпуск партиями**.
2. Выберите **Автоматический подбор** либо **Вручную: указать количество каждой модели**.
3. В ручном режиме установите число физических линий каждой модели (0 — исключить).
4. Текстовая ведомость показывает распределение форм по линиям, время и загрузку, нераспределённые позиции и предупреждения.
5. **Заполнить ручной парк по автоподбору** заменяет ручные числа предложенным набором.
6. Результаты автоматически передаются в **Площади**, **Рабочую силу**, **Склады** и **Сводку** через связанные сигналы. Вкладки, рассчитывающие независимый годовой тоннаж, могут сохранить прежние значения — это ожидаемо.

Ручной ввод **не** запускает скрытое добавление недостающих машин. Если годовой фонд не позволяет выпустить программу, проект помечается незавершённым. При этом установленный парк остаётся в предварительной ведомости площади, чтобы можно было сравнивать варианты.

Пользовательский выбор режима и количеств записывается через `UserChoices` в пользовательскую папку, а также сохраняется в текущей модели `Project`. У проекта пока нет отдельного надёжного формата сохранения/загрузки всей номенклатуры — это следующая самостоятельная задача.

## Что означает «выполнимо»
Это проверка **годового фонда**. Учитываются паспортные формы/ч, совместимость опок (оба размера высот), материал, масса отливки и в форме, введённая загрузка, партии и время переналадок. Дефицит форм показывается явно; при совместном выпуске одна линия может переходить между разными отливками.

Планирование пока **не** учитывает календарь по сменам, наличие оснастки на конкретную смену, обслуживание/простои сверх заданного коэффициента, формирование партии и длительность выдержки, фактическую загрузку заливочных устройств, склад/конвейер, логистику кранов и геометрическую расстановку.

Избыточные линии сохраняются в составе парка, даже если простаивают. Персонал считается по принятым укрупнённым нормам для линий, а не по нормированным операциям каждой отливки; эти нормы требуют независимой инженерной проверки. Недостаточное количество линий не превращается автоматически в меньший заданный выпуск.

## Тестирование
- `tests/test_manual_molding_fleet.py` — ручные числа, совместимость, дефицит/избыток и годовой баланс форм;
- `tests/test_manual_molding_gui.py` — управление через Qt, изменение загрузки, площадей и персонала;
- `.github/workflows/calculation-tests.yml` — запуск тестов в Linux headless;
- `.github/workflows/windows-exe.yml` — Windows-сборка PyInstaller и проверка запуска.

После каждого изменения кода проверяйте соответствующий коммит в GitHub Actions. Сборка EXE и прохождение тестов не означают нормативную пригодность проекта промышленного цеха.
